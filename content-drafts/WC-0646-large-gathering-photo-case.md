## Large family cake case-study framework

**Do not publish until there is a real, approved White Cakes project.** Find an order with a verified guest-serving plan and an original finished-cake photo. Confirm permission to use the image and anonymize personal details unless the family has explicitly approved identification. Never invent a family, celebration, design decision, or testimonial to fill this page.

Record the facts that make the case useful: approximate number of cake eaters, whether other desserts were served, the size chosen, flavour, requested visual theme, and any delivery constraint. State the bakery's actual reasoning for the size recommendation only if it appears in the order notes or is confirmed by the team. Keep estimates clearly labeled as estimates.

Use the photographs to explain visible choices, such as how colour and decoration were balanced on the cake. Captions should describe only what the photo shows. Link to the current cake-size guide and ordering information, and make the article answer a question the existing guides do not already answer.

If no suitable image or verified notes are available, leave the case unpublished. Merge generic serving advice into the existing size guide; a near-identical photo caption is not a new article.
