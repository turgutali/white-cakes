## English

# Which reference photos help when ordering children's birthday cake in Cebu

For a children’s cake, send a reference that shows the theme and another detail only if needed. Explain whether the key is the character silhouette, colours, or mood, and say what may be simplified. This helps keep the design clear and practical to serve.

Use references you have permission to share and ask what the bakery can hand-pipe.

## Cebuano

# Unsang mga litrato nga reference ang makatabang sa pag-order og cake para sa adlawng natawhan sa bata sa Cebu

Ipadala ang reference sa tema ug usa ka detalye kon gikinahanglan. Isulti kon silhouette, kolor o mood ang importante ug unsay pasimplehon. Makatabang kini nga klaro ug sayon i-serve.

Gamita ang reference nga gitugotan ug pangutan-a unsay mapiping.

## Tagalog

# Aling mga reference photo ang makatutulong sa pag-order ng cake para sa kaarawan ng bata sa Cebu

Magpadala ng reference para sa tema at isa pang detalye kung kailangan. Sabihin kung silhouette ng character, kulay, o mood ang mahalaga at ano ang maaaring pasimplehin. Nakakatulong ito para malinaw at praktikal ihain ang design.

Gumamit ng reference na may pahintulot at itanong kung ano ang kayang i-hand-pipe ng bakery.
