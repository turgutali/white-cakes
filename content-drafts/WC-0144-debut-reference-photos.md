## Which reference photos help when ordering debut cake in Cebu

Send a photo of the celebrant’s outfit or event palette only if it helps explain colour, plus one cake reference showing the overall silhouette. Add a close-up only for a detail you truly want considered. Identify the source of each image and label what you like about it.

A reference is direction, not proof that the same design can be reproduced. White Cakes uses hand-piped buttercream and will adapt a brief to size and technique. Say what is flexible and what is essential, then ask for a written interpretation before approving the order.
