## Fit the debut message to the cake’s design and available writing space

A debut cake message can name the celebrant, mark the occasion, or use a short family greeting. Choose one purpose and keep the wording concise so it remains legible next to the design. If including a name and age, decide which detail should stand out most.

Send the exact wording, spelling, capitalization, and punctuation when you ask about the cake. Tell the bakery which elements are essential and ask whether the message fits the selected size and decoration. A longer dedication is usually clearer on a separate card than squeezed onto the cake surface.

Add debut examples to the existing message guide only when they are original and useful. Any photo gallery should feature real cakes with permission, not invented sample orders.
