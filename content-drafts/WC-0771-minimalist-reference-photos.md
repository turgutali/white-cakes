## English

# Which reference photos help when ordering minimalist cake in Cebu

Use reference photos to communicate restraint as well as decoration. One image can show the amount of open space, another the lettering style, and a third the colour. Explain which detail matters so the bakery does not mistake several different minimalist looks for one request.

Add the requested size, flavour, message, and date. Ask for a concise written summary of the design. Use approved images only; an internet reference does not prove the exact finish is available.

## Cebuano

# Unsang mga litrato nga reference ang makatabang sa pag-order og minimalist nga cake sa Cebu

Gamita ang reference photo sa pagpakita sa simplicity ug dekorasyon. Usa ka hulagway sa open space, lain sa estilo sa letra ug ikatulo sa kolor. Isulti unsay importante aron dili masayop og sabot ang panaderya sa daghang lahi nga minimalist look.

Iapil ang gidak-on, flavour, mensahe ug petsa. Pangayo og mubo nga sinulat nga summary sa disenyo. Aprubadong litrato lang gamita; dili pamatuod sa availability sa finish ang internet reference.

## Tagalog

# Aling mga reference photo ang makatutulong sa pag-order ng minimalist na cake sa Cebu

Gamitin ang reference photos para ipakita ang pagiging simple pati dekorasyon. Maaaring ipakita ng isa ang open space, ng isa ang estilo ng lettering, at ng isa ang kulay. Sabihin kung aling detalye ang mahalaga para hindi mapagkamalan ng bakery na iisang request ang magkakaibang minimalist look.

Idagdag ang hinihinging sukat, flavor, mensahe, at petsa. Humingi ng maikling nakasulat na buod ng design. Aprubadong larawan lang ang gamitin; hindi patunay ng availability ng finish ang internet reference.
