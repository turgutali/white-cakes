# White Cakes content production drafts

This folder contains unpublished manuscript drafts derived from the 1,000-item roadmap in `White_Cakes_1000_Content_Calendar.xlsx`.

- Roadmap baseline: 50 existing Journal posts plus 950 proposed content items.
- Drafted so far: 225 candidate manuscripts (including photo-case frameworks that need original image evidence).
- Remaining from the 950-item roadmap: 725.
- Each file records English, Cebuano, and Tagalog title drafts and a recommended canonical target. The titles are not full translations of the article body.
- Most candidates are sections or FAQs to merge into existing canonical guides; they are not approved as 950 separate URLs.
- Do not copy this folder into production or submit the draft URLs for indexing before the full editorial pass is complete.
- Never invent White Cakes prices, serving counts, customer cases, delivery rules, available ingredients, or photo evidence. Recheck time-sensitive details before publication.

The current work is on branch `cebubu/1000-article-drafts`, based on the live `main` commit. The branch has not been pushed. Continue drafting in calendar order, update this count after each batch, and do the site/indexing checks only when the full planned batch is complete.
