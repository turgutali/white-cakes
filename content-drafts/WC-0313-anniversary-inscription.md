## Choose a message that reflects the couple and fits the cake

An anniversary message can name the couple, mark the number of years, or offer a short greeting. Choose one focus instead of trying to include a long dedication, several names, and a date on the same surface. A short line is easier for guests to read and leaves room for decoration.

Send exact names, spelling, punctuation, and the anniversary number to the bakery. Ask whether the wording fits the selected size and design. If you want to include a longer personal note, put it on a card beside the cake.

Add anniversary examples to the shared message guide when they provide genuinely useful phrasing. A photo gallery should use real, permission-cleared cakes and accurate captions.
