## Keep a Signature Marble inscription short enough for the design

The current Signature Marble description has been a 6-inch design with ivory finish, dusty blue marbling, shell border, and one rose; verify the live listing before using those details. If you want a message, choose a short greeting or recipient name so the lettering has room alongside the marble effect and decoration.

Send exact wording and spelling with the order. Ask whether the current design includes an inscription or whether it changes the price, and confirm any requested colour or layout adjustment. A long dedication may work better on a separate card.

Keep message advice in the shared guide and current Signature Marble facts on its product page. A separate gallery needs actual photos that show different, approved lettering layouts.
