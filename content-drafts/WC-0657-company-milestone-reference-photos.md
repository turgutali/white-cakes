## English

# Which reference photos help when ordering cake for a company milestone in Cebu

Useful reference photos show one decision at a time. Send one image for overall shape, another for colour, or a close-up for lettering, and explain which feature matters. Too many images with conflicting styles can make it harder to produce a clear brief for a company milestone.

Include a photo of the event setup only if it helps explain scale or palette; avoid using an image as evidence that the pictured cake is available. If you share company branding, use files approved for the order. Describe what can change, such as the wording or colours, and what should remain consistent.

Pair references with written facts: requested size, guest estimate, venue, serving time, and exact inscription. Ask the baker to summarize the intended design before the company approves payment. For privacy, obtain permission before sharing photos that identify staff or clients.

## Cebuano

# Unsang mga litrato nga reference ang makatabang sa pag-order og cake para sa milestone sa kompanya sa Cebu

Mapuslanong reference photo kay usa ka desisyon matag hulagway ang gipakita. Ipadala ang usa para sa porma, lain para sa kolor o close-up para sa letra, ug isulti unsang feature ang importante. Kon daghan ug nagkasumpaking style ang mga litrato, mahimong lisod himoon ang klarong brief para sa milestone sa kompanya.

Iapil lang ang litrato sa event setup kon makatabang kini sa pagpasabot sa scale o kolor; ayaw gamita ang hulagway isip pamatuod nga available ang cake nga naa niini. Kon magpaambit og branding sa kompanya, gamita ang file nga aprubado para sa order. Isulti unsay mahimong usbon sama sa teksto o kolor ug unsay angay magpabilin.

Ipares ang reference sa sinulat nga impormasyon: gidak-on, banabana sa bisita, venue, oras sa pag-serve ug eksaktong inskripsiyon. Pangayoa sa panaderya nga i-summarize ang tuyo nga disenyo sa dili pa aprobahan sa kompanya ang bayad. Para sa privacy, pangayo og permiso sa dili pa mo-share og litrato nga mailhan ang staff o kliyente.

## Tagalog

# Aling mga reference photo ang makatutulong sa pag-order ng cake para sa mahalagang okasyon ng kumpanya sa Cebu

Kapaki-pakinabang ang reference photo kapag iisang desisyon ang ipinapakita ng bawat larawan. Magpadala ng isa para sa hugis, isa para sa kulay, o close-up para sa lettering, at sabihin kung aling feature ang mahalaga. Kapag maraming larawang magkakasalungat ang style, mas mahirap gumawa ng malinaw na brief para sa company milestone.

Isama lang ang larawan ng event setup kung nakatutulong itong ipaliwanag ang scale o paleta; huwag gawing patunay na available ang cake sa larawan. Kung magbabahagi ng company branding, gumamit ng file na aprubado para sa order. Ipaliwanag kung ano ang puwedeng baguhin, gaya ng wording o kulay, at ano ang dapat manatili.

Itambal ang reference sa nakasulat na detalye: sukat, tantiya ng bisita, venue, oras ng paghahain, at eksaktong inscription. Hilingin sa bakery na ibuod ang nilalayong design bago aprubahan ng kumpanya ang bayad. Para sa privacy, humingi ng pahintulot bago magbahagi ng larawang makikilala ang staff o kliyente.
